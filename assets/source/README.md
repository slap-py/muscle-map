# Original anatomical sources

Keep unmodified original files here. No anatomical meshes have been imported.
Before importing, record URL, immutable revision, download date, SHA-256,
object names, object-specific licenses, authors and atlas-ID mapping in a manifest.
Keep upstream licenses beside each source. See ../../credits.md.
Large originals should use Git LFS or a reproducible download manifest.
Processed runtime assets belong in public/models/.
